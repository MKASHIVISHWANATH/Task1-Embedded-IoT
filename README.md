## 🛠️ Mini Project: Motion Detection Alarm
**Objective:** A security system that triggers a buzzer and LED when motion is detected using a PIR sensor.

### Components Used:
- **Microcontroller:** Arduino UNO
- **Sensor:** PIR Motion Sensor (HC-SR501)
- **Actuators:** Piezo Buzzer, Red LED
- **Software:** Arduino IDE / Tinkercad Simulator

### Working Principle:
1. The PIR sensor detects infrared radiation changes (warm bodies).
2. It sends a HIGH signal to the Arduino.
3. The Arduino triggers the Buzzer and LED alarm.
